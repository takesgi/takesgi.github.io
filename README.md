# 二等ドローン学科試験 対策ドリル

二等無人航空機操縦士 学科試験の対策アプリです。ブラウザで動き、インストールするとオフラインでも使えます。

国土交通省「無人航空機の飛行の安全に関する教則」第5版（令和8年7月14日適用）準拠。
全420問・模擬試験・暗記カード67枚・教則ダイジェストを収録。復習の自動スケジュール、節別の弱点分析が加わった。

学習記録は利用者の端末内にのみ保存されます。外部への通信は一切ありません。

本アプリは学習用の教材です。試験・実務の最終的な根拠は、必ず教則本文および航空法令をご確認ください。
国土交通省および指定試験機関とは関係のない、非公式の学習用アプリです。

## このリポジトリの中身

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（問題データ・画面をすべて内蔵。文字は端末のフォントで表示） |
| `manifest.webmanifest` | アプリ名・アイコン・ショートカットの定義 |
| `sw.js` | オフライン動作・更新通知・学習リマインダー（index.html を差し替えるだけで最新版が届きます） |
| `icons/` | ホーム画面用アイコン（PNG 5種） |
| `.nojekyll` | **消さないでください。** `.well-known/` などドット始まりのフォルダを配信するために必要です |
